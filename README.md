# Dr. Gustavo Siedschlag

Site profissional estático publicado em https://drgustavosied.com.br/.

## Páginas

- `index.html`: apresentação principal em português e inglês, tratamentos, consulta e endereços.
- `florianopolis/index.html`: atendimento na GM Dental Boutique e informações locais.
- `curriculo/index.html`: formação, trajetória internacional, atuação e pesquisa selecionada.
- `sitemap.xml` e `robots.txt`: descoberta e rastreamento das páginas públicas.
- `assets/dr-gustavo-siedschlag.jpg`: fotografia original, compartilhada entre as páginas.

O projeto não exige dependências de frontend nem etapa de compilação. O Netlify publica a raiz do repositório, conforme `netlify.toml`. Atualizações de `main` acionam a publicação pelo webhook configurado entre GitHub e Netlify. Não incluir URLs privadas de hooks, tokens ou configurações de autenticação no repositório.
